# Examples gallery

Below are worked examples demonstrating SOCF on different process models.

For full runnable notebooks with output, see the [`Examples/`](https://github.com/Saketdhake/Self_Optimizing_Control/tree/main/Examples) folder in the repository.

## Available examples

### {doc}`cstr_quickstart`
A CSTR (Continuous Stirred-Tank Reactor) case study demonstrating the basic workflow: define a Pyomo model, specify disturbances and CV designs, run the analysis, and interpret the loss matrix.

### {doc}`solver_notes`
Notes on IPOPT configuration, common solver issues, and tips for debugging infeasible results.

```{tip}
All examples assume IPOPT is installed and available on your PATH. See {doc}`../installation` for setup instructions.
```
